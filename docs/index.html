    Styr boten herfra

    Alle kan se siden. For å endre innstillinger og trykke på knappene må du koble til med en nøkkel fra GitHub. Nøkkelen lagres bare i denne nettleseren.

    1. Åpne github.com/settings/personal-access-tokens/new.
    2. Gi den et navn, velg Only select repositories og velg dette repoet.
    3. Under Repository permissions: sett Contents og Actions til Read and write.
    4. Trykk Generate token, kopier nøkkelen og lim den inn her.

    Koblet til. Knappene og innstillingene virker.

    Innstillinger

    Skilt med komma, slik de heter hos Yahoo Finance. Amerikanske skrives rett fram (AAPL). Oslo-aksjer slutter på .OL (EQNR.OL), men gratiskursene for Oslo er 15 minutter forsinket.
